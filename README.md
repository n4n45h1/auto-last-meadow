# Auto last meadow 

Simple Discord last meadow autoclicker. Automatically starts clicking when loaded.

## Usage

### Installation

1. Open Discord in your browser
2. Open Developer Tools (F12 or Right-click → Inspect)
3. Go to Console tab
4. Paste the script and press Enter
5. The bot will start automatically

### Controls

```javascript
// Pause the bot
window.adventureClicker.stop()

// Resume the bot
window.adventureClicker.start()

// Check status
window.adventureClicker.status()

// Unload the bot
window.adventureClicker.unload()
```
